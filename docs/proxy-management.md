# 代理管理与账户切换

2026-10-21。本页属于 AIStudio2API 原生网页控制台，需要管理员密码会话；模型 Key、管理 API Key 和免密回环访问不能访问这些接口。Gemini Manager 的配置及流程没有在本轮修改。

## 使用

1. 在“代理管理”添加来源名称、HTTPS 下载地址和 SOCKS5／HTTP／HTTPS 类型，默认 SOCKS5。Webshare 文本链接在页面填写，不内置于源码。已保存的地址只显示“已配置”，编辑留空保留原地址。
2. 点击“更新列表”。支持 `host:port:user:password` 和完整代理 URL；用户名和密码规范编码。更新去重并保留旧条目的启停、检测状态，移出来源的条目不再参与分配；错误或空列表保留上一份有效代理库。
3. 选择代理或当前筛选全集进行测试。默认并发 10，可选 1–50，单代理总预算 15 秒。检测出口 IP 与 AI Studio 首页网络可达性，显示请求延迟及 AI Studio 延迟；受限、连接、DNS、认证、TLS 和超时分别标注。不携带账户 Cookie，不登录，不调用模型，也不执行带宽测速。
4. 在账户行点击“切换代理”，选择指定代理或随机设置；勾选账户后可批量随机设置，每批最多 200 个。候选必须启用、来源有效并在 24 小时内测试通过，排除该账户当前实际出口。不同账户允许共用一个代理，无候选时失败，不回退直连。

来源仅手动更新。新页面与现有全局自动代理池分开，更新、停用条目或检测不会自动修改账户出口。更换认证内容产生新的未测试条目。表格默认 50 条／页，最多 200 条；检测任务接受后台筛选快照，最多 20,000 项，单次来源下载最多 5 MiB。

列表及任务结果只显示不含认证的主机端口、来源、状态、延迟、版本和安全错误码。下载地址、完整代理 URL 及认证只保存在服务端私有输入和存储中；不进入列表响应、日志或浏览器存储。浏览器 sessionStorage 仅保存随机任务定位键和任务 ID。生产中原有账户编辑接口仍保留其原手工代理协议，没有扩大其回传范围。

## 存储与一致性

代理库位于配置文件所在目录下的 `runtime/proxies/proxies.db`。独立 SQLite 使用版本化初始化、事务和私有文件权限，不修改现有管理数据库或账户表。Docker 默认位于持久化 `/data` 下，发布时必须保留既有数据卷。代理库不可用时页面返回明确错误，其他控制台功能继续运行。

来源更新在下载解析完成后以来源版本 CAS 事务合并；网络期间不占数据库事务。HTTPS 下载不跟随跳转，不使用环境代理；DNS 解析及实际拨号均拒绝回环、私网、链路本地和云元数据地址。检测客户端同样校验实际代理连接地址。AI Studio 仅接受正常响应及指向 Google HTTPS 的跳转作为网络通过，401／403／429 标记受限。这些结果不证明账户登录或模型可用。

账户切换在受理时固定代理、账户双版本和提交操作 ID，随后通过既有账户租约、文件日志与协调器提交。只修改代理，保留 Cookie、停用状态、语言、时区及其他设置；归档／删除跳过。真实变化只递增 stateVersion；credentialVersion 不变。繁忙账户最多等待本项 30 秒预算，不强制中止运行请求。已提交修改与运行时客户端通过现有发布链路更新。

同一幂等键与请求内容返回原任务，内容不同返回冲突。原提交日志证明和账户版本／出口读回全部一致后才显示成功；提交未知不重抽、不重放。可通过任务结果的“核对提交”只读查询原操作。已知运行时发布失败保留“配置已提交，运行时生效尚未确认”，普通核对不会伪造成功；进程重新装配后再根据原日志和当前状态核对。

关闭页面不取消任务；停止保留已提交修改。检测停止后未开始条目以一次数据库更新收敛，避免对大批次逐项执行网络工作。进程重启后未完成任务标为中断，只核对原账户提交，不自动恢复执行。

## 控制台接口

所有路径受现有密码会话、同源检查、请求体限制与 `Cache-Control: no-store` 保护，不新增 `/api/manage/v1` Key 权限。

| 接口 | 用途 |
| --- | --- |
| `GET/POST /api/proxies/sources` | 安全来源列表／创建 |
| `PUT/DELETE /api/proxies/sources/{id}` | 带 revision 的编辑／移除；下载地址只写不读 |
| `POST /api/proxies/sources/{id}/refresh` | 下载并 CAS 合并来源 |
| `GET /api/proxies`、`GET /api/proxies/stats` | SQL 分页过滤／统计 |
| `PATCH /api/proxies/{id}` | 带 revision 的启停 |
| `POST /api/proxies/account-contexts` | 最多 200 个指定账户的安全身份和双版本快照 |
| `POST /api/proxies/jobs` | `kind=test/assign`，显式代理 ID／筛选快照或账户目标；必须有 Idempotency-Key |
| `GET /api/proxies/jobs`、`GET /api/proxies/jobs/{id}` | 最近任务／分页结果 |
| `GET /api/proxies/jobs/by-key/{key}` | 受理回执丢失时只读定位原任务 |
| `POST /api/proxies/jobs/{id}/cancel`、`reconcile` | 停止／只核对原提交，不重执行 |

来源下载器通过 `RegisterDownloader` 扩展。默认提供 Webshare 和通用文本实现，检测与账户设置流程不依赖供应商。
