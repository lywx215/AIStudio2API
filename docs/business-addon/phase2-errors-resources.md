# 第二阶段：错误、退避和资源预算

2026-10-22，接续第一阶段稳定账号运行时。所有实现仍在 Business 附加模块内；原 AI Studio 的账号池、WAA、文件和协议流程不参与。

## 错误与调度

运行时保留安全的错误类别、发生阶段、HTTP/规范状态码、允许列表内的 reason、提交/输出标志及时间。原始上游消息、响应正文、URL、Cookie、JWT 不进入这些状态字段。`submitted` 表示生成已交给 HTTP transport 尝试发送，不能保证服务端是否接收；`output_started` 表示已经尝试交付非空内容。

| 情况 | 处理 |
|---|---|
| 本地参数/资源错误、调用方取消、下游写失败 | 不使账号失效，不增加退避次数 |
| 上游普通 400/404 等请求拒绝 | 保留请求拒绝分类，不作为认证失效 |
| 普通 403 或模型权限拒绝 | `permission_denied`，保留认证缓存 |
| 401，或明确认证失效的 403 | 清除当前 JWT，`auth_required`；同凭据历史证据仍是历史 |
| 429 | 配额退避，基准 15 秒 |
| 网络/超时/5xx、协议损坏 | 暂态或协议退避，基准 2 秒 |

连续可退避失败使用指数增长及半值至全值随机抖动，本地上限 5 分钟。合法 `Retry-After` 秒数/HTTP-date 作为等待下限，单独限制在 24 小时。成功终止清除连续失败与冷却；标签/配置保存不会重置它们，凭据版本改变会使旧状态失效。不重放生成、不在输出后切换账号。冷却到期只允许下次显式请求重新尝试，不自动发送探测。

## 资源限制

配置新增 `max_inflight_bytes`，默认 256 MiB，范围 64–4096 整数 MiB。旧 schema-1 配置缺省此字段时兼容默认值；显式零、null、越界和非整 MiB 拒绝。配置可热更新，降低到当前占用以下不撤销在途预算，只拒绝新增占用。

生成、文件上传和下载共享预算。生成读取正文前预留 32 MiB，之后对正文缓冲、附件字符串/解码、文件快照等在分配前申请额度；附件上传通过有界 base64 reader 发送，避免同时保留完整 base64 字符串与序列化 JSON。取消禁止继续申请，实际操作结束才归还仍被持有的额度。

预算是应用缓冲和预留空间的准入限制，不是 Go RSS 测量值，也不是进程级内存隔离。每请求仍保留 68 MiB 原始正文、1 MiB 文本、32 个/累计 50 MiB 附件、4 MiB 输出等限制。单请求硬限制为 413，共享预算不足为 429。磁盘配额、TTL、文件归属与并发限制继续生效。

状态提供 `resources.limit_bytes/in_use_bytes/available_bytes`。`generation_ready` 和模型 `schedulable` 同时考虑账号、并发槽和至少 32 MiB 生成预留；这不保证任意大小请求都能被接收。前端显示 MiB 编辑、占用、冷却和安全错误信息，不主动认证或探测模型。

## 验证

最终297项Go顶层测试、149项Web测试及静态检查通过。真实Argon流式在热降预算后正常完成，TXT/PDF标记与计算正确，结束时占用归零。具体证据见 [validation.md](validation.md) 和 [本轮汇总](evidence/phase2-summary-20261022.json)。测试覆盖错误分类、确定性退避、预算热更新、超限预检、取消归还和原生SDK/文件组合；没有故意制造真实配额或认证失败。

多轮、systemInstruction、tools、真实 token usage/countTokens 和未经证实的高级参数映射不因此扩展。全局 `live_verified` 仍为 false。
