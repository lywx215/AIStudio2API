## 冻结接口

| 操作 | 请求 | 返回 |
| --- | --- | --- |
| 列表 | `GET /api/management-keys` | `{data:{items:ManagementKey[]},requestId}` |
| 创建 | `POST /api/management-keys`，`{name,scopes,expiresAt?}` | `{data:{key:ManagementKey,token},requestId}` |
| 撤销 | `DELETE /api/management-keys/{id}` | `{data:{id,revoked:true},requestId}` |

只发送同源 console session Cookie；显式 `credentials:same-origin`、`cache:no-store`、`redirect:error`，写请求携带 `X-Requested-With: XMLHttpRequest`。不使用模型 Key、管理 Bearer 或配对凭证。页面进入/刷新重新检查原生会话；登录关闭、缺失会话以及服务端 401/403 均关闭管理操作并显示登录要求。真正授权仍由服务端 ConsoleAuthorizer 决定。

DTO 与 `openapi.json`/`internal/managementcontract` 对齐；三种模板由测试直接与 OpenAPI 比较：readonly 包含 `audit:read`，operator 排除 export/archive/settings:write/audit:read，admin 含全部 12 项。自定义权限至少一项。固定有效期及本地时间输入均发送 UTC 三位毫秒字符串；永不过期省略 `expiresAt`。

列表仅接受六项 metadata 字段：`id/name/scopes/createdAt/expiresAt/revokedAt`；拒绝额外 token/hash 等字段，不伪造 token、hash 或撤销时间。已撤销优先于已过期，到期边界按 `expiresAt <= now` 判定并随时钟更新。

令牌只从创建响应进入当前组件内存；关闭弹窗、卸载、会话失效和 pagehide 均清理。异步创建/复制的迟到结果不能重新打开已关闭令牌。不写 localStorage、sessionStorage、URL 或日志；错误展示使用固定文案，不反射原始响应或错误消息。复制失败保留当前弹窗并提供手动保存提示。

创建/撤销丢失响应、畸形成功响应或持久化错误显示“结果未确认”，阻止继续写入直至刷新核对；不自动重试、不报假成功。撤销须确认，仅刷新 Key 列表；成功返回的 revoked 状态可在列表刷新失败时保留，时间仍只使用服务端 metadata。
