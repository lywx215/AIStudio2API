## G0 装配接口（无需修改冻结公共契约）

```go
target, err := newManagementVerificationTarget(managementVerificationTargetOptions{
    Accounts: coordinator, // SnapshotCredentials 窄接口，真实管理协调器可直接传入
    TempDir: "", // OS temp；禁止指向生产 auth/runtime
    Environment: func(ctx context.Context, nativeID string) (managementVerificationEnvironment, error) {
        // 由 G0 读取当前配置快照及该账号的有效代理/locale/timezone。
        // WAABackend 仅 go/camoufox；camoufox 必须提供已准备的 CamoufoxPath。
        // 返回值字段：WAABackend, CamoufoxPath, Proxy, Locale, Timezone, InitTimeout。
    },
})
verifier, err := managementverify.New(contract.VerifierOptions{Target: target})
```

Environment 在每次 Open 时解析，无需绑定生产 worker/pool。G0 可以从当前 generation 的安全账号配置或显式配置快照提供环境；目标本身不读取真实配置文件，不发现或下载浏览器。go 后端强制 ExecutablePath 为空；camoufox 使用 G0 已准备路径。两者均使用新临时状态文件、单账号池、全新 worker，并在 Close 清理。

可选私有扩展 `managementverify.CandidateSource.RefreshedCandidate(context.Context) (*contract.CredentialMaterial,error)` 由真实 session 实现；冻结 VerificationSession 无需改签名。仅传给 Verify 的非 nil Candidate 会返回刷新后私有副本，保留原 origins/原生扩展，调用者用原双版本 CAS 后提交。Verifier 不提交、发布或修改账号状态。

协议 core `aistudio.Client.Generate` 被单次 protected transport gate 包裹；仅允许固定账号/模型的 GenerateContent 实际 RPC，拒绝 Build、assistant、interaction、重复/续写。未使用 PooledService 或普通 tracked 路由/重试。实际通道由已发送 RPC 分支及真实响应确定。

## 身份证据来源

Google ListAccounts 使用 OS temp 内 worker 导出的同一 Cookie 会话；只验证 authuser=0 的第一账号。严格检查邮箱、Gaia ID、valid=1、signedOut=0、verified=1。未知格式/字段缺失失败；不会扫描 HTML 邮箱或相信 account label/auth extension。

字段顺序依据 Chromium 官方源代码：[ParseListAccountsData](https://chromium.googlesource.com/chromium/src/+/refs/tags/138.0.7156.0/google_apis/gaia/gaia_auth_util.cc)。本轮仅阅读公开源代码，未带凭据联网。
